# Firmic B14 — OS Bootstrap

Copy `src/os/*` into the frontend `src/os/` folder and replace `pages/_app.tsx`.

No package installation is required.

Test with:

- Ctrl+K or Cmd+K
- `/` outside form fields
- Arrow keys and Enter
- Mobile floating search button
- Search for Tasks, Billing, Sonny, Documents, or Reports

Future modules can call `registerCommands()` through `useOS()`.
